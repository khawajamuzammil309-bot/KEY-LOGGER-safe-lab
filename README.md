# M | Keylogger - Safe Lab Version

A simple Python-based Keylogger made for learning and internship purpose only.

Disclaimer: This is a SAFE LAB VERSION by M. It does NOT capture keys from the whole computer. It only logs what is typed inside this program's own window. It was tested only on my own Kali Linux machine.

## What I Learned

- How keyloggers work in Cyber Security
- How attackers steal data using keyloggers
- How to detect and prevent keylogger attacks
- Importance of ethical hacking and safe testing

## How It Works

1. Program starts and asks for input
2. Whatever user types inside this program's window is taken by input()
3. That text is saved in a local file named keylog.txt
4. Type exit to stop the program

## How To Run

Run: python3 keylogger.py
Test Input: hello test 123
Check Log File: cat keylog.txt

## How To Stay Safe From Keyloggers

- Don't download cracked software
- Keep antivirus updated
- Don't type passwords on unknown computers
- Use 2-Factor Authentication (2FA)
